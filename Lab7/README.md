**Виконав:** Савлик Андрій, студент 2 курсу спеціальності "Апаратне програмування", групи АП-21

Даний проект присвячений вивченню та практичному застосуванню каркасу колекцій (Java Collections Framework). У роботі реалізовано алгоритми керування списками об'єктів та структурою даних "ключ-значення" для ефективного пошуку та маніпуляції даними.

## 📁 Структура проекту

Проект розділений на два основні модулі та допоміжні класи:

* **`Task1.java`**: Основний клас першого завдання (робота з `ArrayList`).
* **`Task2.java`**: Основний клас другого завдання (робота з `HashMap`).
* **`models/Car.java`** та **`models/Driver.java`**: Класи-моделі для опису характеристик автомобілів та водіїв.
* **`utils/Helper.java`**: Допоміжний клас із статичними методами для вибору випадкового елемента та виведення повідомлень.

## 🛠 Опис завдань

### Завдання 1: Керування автопарком (`List`)
У цьому модулі реалізовано динамічний список об'єктів `Car`. Програма виконує наступні кроки:
1. **Ініціалізація**: Створення та заповнення списку 10-ма різними автомобілями.
2. **Масова модифікація**: 
   * Для першої половини списку: збільшення потужності двигуна на 10% та призначення нових водіїв.
   * Для кожного другого автомобіля: підвищення потужності на 10% та ціни на 5%.
3. **Умовна перевірка**: Автоматичне оновлення досвіду водія, якщо він відповідає критеріям (вік > 25 років та досвід < 5 років).
4. **Рандомізація**: Виклик таксі за допомогою генератора випадкових чисел.

### Завдання 2: Телефонна книга (`HashMap`)
Реалізація асоціативної карти, де ключем є прізвище абонента, а значенням — номер телефону. Продемонстровано:
* Додавання та ітерацію по записах.
* Швидкий пошук за ключем (`containsKey`).
* Перевірку наявності конкретного номера телефону (`containsValue`).
* Динамічне видалення записів та контроль розміру колекції.

## ⚙️ Технічні деталі та особливості реалізації

* **Динаміка**: Використання `ArrayList` дозволяє програмі гнучко працювати з кількістю об'єктів без жорсткого обмеження розміру масиву.
* **Ефективність**: Використання `HashMap` забезпечує константний час доступу до даних при пошуку абонентів за іменами.
* **Чистий код**: Використання методу `toString()` у моделях для зручного виведення поточної інформації про об'єкти в консоль.
* **UTF-8**: Традиційно налаштовано коректне відображення кирилиці для зручності взаємодії з користувачем.
