Цей проект присвячений вивченню методів (функцій) у мові Java. Робота демонструє поділ логіки програми на окремі модулі (класи), створення статичних методів із параметрами та значеннями, що повертаються, а також їх інтеграцію в єдиний робочий процес у головному класі.

## 📁 Структура проекту

Проект розбитий на кілька файлів згідно з принципом єдиної відповідальності (Single Responsibility Principle):

* **`Main.java`**: Головний клас-координатор, що містить точку входу (`main`). Він ініціалізує тестові дані, викликає методи з інших класів та виводить зведені результати у консоль.
* **`Task1.java`**: Клас із логікою для геометричних обчислень.
* **`Task2.java`**: Клас із математичною логікою пошуку мінімуму.
* **`Task3.java`**: Клас для роботи з рядками та форматуванням даних.
* **`Task4.java`**: Клас із алгоритмом обробки одновимірних масивів.

## 🛠 Опис завдань

1. **Площа квадрата (`Task1`)**: Створення методу `getSquareArea`, який приймає довжину сторони типу `double` і обчислює площу фігури.
2. **Мінімум трьох чисел (`Task2`)**: Реалізація методу `getMin`, що використовує вкладений виклик вбудованої функції `Math.min` для знаходження найменшого значення серед трьох переданих цілих чисел.
3. **Обробка масивів та рядків (`Task3`)**: Створення методу `getArrayAsString`, який приймає масив цілих чисел та акуратно форматує його у текстовий рядок через кому.
4. **Пошук максимуму (`Task4`)**: Реалізація класичного алгоритму в методі `getMax` для проходу по масиву та знаходження його найбільшого елемента.

## ⚙️ Технічні деталі та особливості реалізації

* **Модульність коду**: Кожне завдання винесено в окремий клас зі статичними методами, що робить код читабельним, легко тестованим та зручним для повторного використання.
* **Оптимізація рядків**: У завданні 3 замість звичайної конкатенації рядків (`+`) у циклі використовується клас `StringBuilder`, що значно економить пам'ять та пришвидшує роботу програми.
* **Локалізація**: У головному класі застосовано налаштування `System.setOut` з кодуванням `UTF-8` для правильного відображення української мови.
