Цей проект присвячений розробці десктопного додатка з використанням бібліотеки Java Swing. Програма реалізує графічний калькулятор для обчислення відстані польоту тіла, кинутого під кутом до горизонту.

## 📁 Структура проекту

* **`Variant15.java`**: Головний клас додатка. Містить логіку побудови інтерфейсу, розміщення кнопок, текстових полів та обробку математичних розрахунків.

## 🛠 Опис функціоналу (Варіант 15)

Програма дозволяє користувачеві вводити дані та отримувати результат у зручному вікні.

### Основні можливості:
1. **Графічне вікно**: Використання панелі JPanel для точного розміщення елементів.
2. **Введення даних**: Поля для початкової швидкості (v0) та кута кидка (alpha).
3. **Автоматичний розрахунок**: Обчислення відстані польоту за формулою: 
   **h = (v0^2 * sin(2 * alpha)) / g**, де g = 9.81 м/с.
4. **Валідація**: Якщо замість чисел ввести текст, програма виведе зрозуміле повідомлення про помилку через спливаюче вікно.
5. **Захист результатів**: Поле виводу результату заблоковано, щоб його неможливо було змінити вручну.

## ⚙️ Технічні деталі

* **Математика**: Кути автоматично переводяться з градусів у радіани для коректних розрахунків.
* **Надійність**: Додаток запущено в окремому потоці (EventQueue), що є стандартом для стабільної роботи графічних інтерфейсів у Java.
* **Кодування**: Використовується стандарт UTF-8 для правильного відображення українського тексту.
