# Лабораторна робота №8: Робота з файловою системою та потоками введення-виведення в Java

**Виконав:** Савлик Андрій, студент 2 курсу спеціальності "Апаратне програмування", групи АП-21

Даний проект демонструє навички роботи з текстовими файлами, обробку виняткових ситуацій (`IOException`) та використання генератора випадкових чисел для створення динамічного контенту.

## 📁 Структура проекту

Проект розділений на два основні класи для чіткого розподілу відповідальності:

* **`Main.java`**: Вхідна точка програми. Містить налаштування середовища (кодування), задає константи (назва файлу, діапазон чисел) та координує виконання завдань.
* **`FileTask.java`**: Клас, що містить бізнес-логіку роботи з файлами. Реалізовує методи для перевірки існування файлу, запису послідовностей та їх зчитування.

## 🛠 Опис функціоналу

Програма виконує наступний алгоритм:

1. **Контроль цілісності файлу**: Перед записом програма перевіряє наявність цільового файлу. Якщо файл відсутній, він створюється автоматично засобами класу `File`.
2. **Генерація та запис даних**:
   * Використовується клас `Random` для створення послідовності з 15 чисел.
   * Числа генеруються у заданому користувачем діапазоні `[b1, b2]`.
   * Запис здійснюється у текстовому форматі через пробіл за допомогою `FileWriter`.
3. **Читання та візуалізація**:
   * Реалізовано посимвольне зчитування даних із файлу за допомогою `FileReader`.
   * Результат виводиться у консоль у структурованому вигляді.

## ⚙️ Технічні деталі та особливості реалізації

* **Безпека ресурсів**: Запис та читання реалізовані через конструкцію **try-with-resources**. Це гарантує, що файлові потоки будуть закриті навіть у разі виникнення помилки, запобігаючи витоку пам'яті.
* **Гнучкість діапазонів**: Програма дозволяє легко змінювати межі генерації випадкових чисел (наприклад, від 5 до 100) безпосередньо у класі `Main`.
* **Обробка помилок**: Використання блоків `try-catch` дозволяє програмі не "падати" при помилках доступу до файлів, а виводити інформативне повідомлення користувачу.
* **Кодування**: Для коректної підтримки української мови та запобігання появі "ієрогліфів" у консолі встановлено стандарт `UTF-8`.
