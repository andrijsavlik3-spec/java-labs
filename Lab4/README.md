# Лабораторна робота №4: Одновимірні масиви та базові алгоритми в Java

**Виконав:** Савлик Андрій, студент 2 курсу спеціальності "Апаратне програмування", групи АП-21

Цей проект присвячений роботі з одновимірними масивами в мові Java. Лабораторна робота демонструє створення, ініціалізацію, обхід масивів за допомогою циклів (`for` та `while`), а також виконання базових алгоритмічних операцій над їхніми елементами.

## 📁 Структура проекту

Проект складається з головного класу для комплексного запуску та окремих файлів для кожного завдання:

* **`Main.java`**: Головний клас, який послідовно викликає та демонструє результати всіх чотирьох завдань у єдиному потоці виконання.
* **`Task1.java`**: Завдання 1. Створення та автоматичне заповнення масивів парними та непарними числами.
* **`Task2.java`**: Завдання 2. Різні способи обходу масиву (всі елементи, лише парні/непарні індекси, зворотній порядок) за допомогою циклів `for` та `while`.
* **`Task3.java`**: Завдання 3. Робота з масивами дійсних чисел (`double`) та обчислення загальної суми всіх елементів.
* **`Task4.java`**: Завдання 4. Пошук та модифікація елементів масиву за заданою умовою (зміна знаку всіх непарних чисел).

## 🛠 Опис завдань

1. **Генерація числових послідовностей**: Програма створює два порожні масиви розміром по 50 елементів і заповнює один із них парними числами, а інший — непарними.
2. **Ітерація та фільтрація індексів**: Демонстрація гнучкості циклів. Виведення елементів масиву прямим і зворотним ходом, а також вибіркове виведення елементів, що стоять на парних або непарних позиціях (індексах).
3. **Агрегація даних**: Простий алгоритм накопичення (акумуляції) для знаходження суми масиву чисел з плаваючою крапкою.
4. **Умовна заміна елементів**: Прохід по масиву цілих чисел з перевіркою кожної змінної на непарність (за допомогою оператора ділення по модулю `%`). Якщо число непарне — його знак змінюється на протилежний.

## ⚙️ Технічні деталі та особливості реалізації

* **Незалежність коду**: Архітектура дозволяє запускати кожне завдання як окремо (через класи `Task1`, `Task2` і т.д.), так і всі разом за допомогою файлу `Main.java`.
* **Локалізація**: Для правильного відображення українських літер у консолі налаштовано вивід у форматі `UTF-8` за допомогою об'єкта `PrintStream`.
