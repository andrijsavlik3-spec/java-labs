Цей проект є комплексною демонстрацією ключових принципів об'єктно-орієнтованого програмування (ООП) у мові Java. Програма ілюструє використання класів, багаторівневого спадкування, абстрактних класів, перевантаження та перевизначення методів на прикладі різних предметних областей.

## 📁 Структура проекту

Проект складається з головного класу `Main.java` та кількох незалежних ієрархій класів:

* **Модуль користувачів**: `Person.java`
* **Модуль зв'язку**: `Phone.java`
* **Ієрархія геометричних фігур (`Shape`)**: `Shape.java`, `SolidOfRevolution.java`, `Cylinder.java`, `Ball.java`, `Pyramid.java`.
* **Ієрархія автомобілів (`Car`)**: `Car.java`, `Sedan.java`, `Truck.java`.
* **Модуль роботи з матрицями**: `Matrix3x3.java`, `NamedMatrix.java`.

## 🛠 Опис завдань

1. **Базові класи та конструктори (`Person`)**: Створення класу з полями для зберігання імені та віку. Реалізовано декілька конструкторів (за замовчуванням та з параметрами) та базові методи дії.
2. **Перевантаження методів (`Phone`)**: Демонстрація перевантаження конструкторів (overloading) та методів `receiveCall`. Використано механізм аргументів змінної довжини (varargs) у методі `sendMessage` для відправки повідомлень на довільну кількість номерів.
3. **Спадкування геометричних фігур**: Побудова багаторівневої ієрархії класів. Базовий клас `Shape` передає властивість `volume` (об'єм) нащадкам. Клас `SolidOfRevolution` додає радіус, а конкретні фігури (`Cylinder`, `Ball`, `Pyramid`) розраховують свої параметри за відповідними математичними формулами через конструктор.
4. **Абстрактні класи (`Car`)**: Використання абстрактного класу `Car` з абстрактним методом `brake()`. Класи-нащадки `Sedan` та `Truck` реалізують цей метод по-своєму, деталізуючи логіку гальмування.
5. **Обробка двовимірних масивів (Варіант 15)**: Створення базового класу `Matrix3x3` для зберігання, виведення та математичного транспонування (повороту) матриці розміром 3х3. 
6. **Розширення функціоналу (`NamedMatrix`)**: Клас `NamedMatrix` наслідує `Matrix3x3`, додаючи нові поля-метадані (ім'я та дату створення матриці). Метод `printMatrix()` перевизначено для виведення додаткової інформації перед викликом логіки суперкласу (`super.printMatrix()`).

## ⚙️ Технічні деталі та особливості реалізації

* **Поліморфізм та Перевизначення (Overriding)**: Активне використання анотації `@Override` у дочірніх класах для зміни поведінки методів батьківського класу.
* **Ключове слово `super`**: Застосовується для виклику конструкторів батьківських класів та звернення до їхніх методів.
* **Локалізація**: У класі `Main` використано блок `try-catch` та налаштування `System.setOut` з `StandardCharsets.UTF_8` для безпечного та правильного виведення українського тексту в консоль.
