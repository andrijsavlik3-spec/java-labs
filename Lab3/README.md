Цей проект присвячений глибокому вивченню циклів (`for`, `while`), створенню вкладених циклічних конструкцій, табулюванню математичних функцій та основам роботи з потоками (`Thread`) для керування безкінечними циклами.

## 📁 Структура проекту

Проект розділений на окремі файли-завдання, кожне з яких демонструє певний аспект роботи з циклами:

* **`Task1.java`**: Базове використання циклів `for` та `while` для багаторазового виведення рядка в консоль (50 ітерацій).
* **`Task2And3.java`**: Робота з подвійними вкладеними циклами для імітації роботи електронного годинника (години та хвилини).
* **`Task4.java`**: Потрійні вкладені цикли для створення повноцінного таймера (години, хвилини, секунди).
* **`Task5.java`**: Складне алгоритмічне завдання. Табулювання функції $y = 3x - 4\sin(x^2)$ на проміжку `[0.0, 4.0]` з кроком `0.2`. Включає інтерактивне введення меж діапазону та підрахунок кількості значень, що потрапили у цей діапазон.
* **`ConsoleLoopStop.java`**: Демонстрація зупинки нескінченного циклу за допомогою окремого потоку (`Thread`) зчитування даних із клавіатури та використання потокобезпечної змінної `volatile`.

## ⚙️ Технічні деталі та особливості реалізації

* **Математичний апарат**: Для обчислення функції у 5-му завданні використовуються методи класу `Math` (`Math.sin`, `Math.pow`).
* **Багатопотоковість**: Використання `Thread` та лямбда-виразів `() -> {}` для паралельного виконання основного циклу та очікування вводу від користувача.
* **Синхронізація**: Застосування ключового слова `volatile` для прапорця `keepRunning`, що гарантує миттєву видимість змін змінної для всіх потоків.
* **Локалізація**: Налаштування `System.setOut` з кодуванням `UTF-8` для правильного відображення української мови.
