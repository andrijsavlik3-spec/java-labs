Цей проект демонструє використання умовних операторів, математичних функцій (клас `Math`) та механізмів обробки винятків (`try-catch`) у мові програмування Java.

## 📁 Структура проекту

* **`Lab2.java`**: Головний і єдиний клас програми, який містить реалізацію п'яти математичних та логічних завдань у вигляді інтерактивного консольного додатку.

## 🛠 Опис завдань

Програма послідовно виконує наступні завдання:

1. **Квадратне рівняння**: Отримання коефіцієнтів (a, b, c) та обчислення коренів рівняння за допомогою дискримінанту.
2. **Координатна площина**: Визначення квадранту (I, II, III, IV), в якому знаходиться точка із заданими координатами (x, y).
3. **Аналіз числа**: Перевірка введеного цілого числа на відповідність двом умовам одночасно: чи є воно двозначним та чи є воно парним.
4. **Обчислення функції f(x)**: Розрахунок значення складної кусково-заданої функції з використанням методів (`Math.cos`, `Math.sin`, `Math.log`, `Math.abs`, `Math.pow`).
5. **Дні тижня**: Використання оператора `switch` для визначення того, чи є введений день (1-7) робочим або вихідним.

## ⚙️ Технічні деталі та особливості реалізації

* **Клас `Math`**: Активне використання вбудованих математичних функцій для розрахунку коренів, степенів та модулів.
* **Стійкість до помилок (Fault Tolerance)**: Програма обгорнута в цикл `while` та блок `try-catch`. Якщо користувач вводить літери замість чисел або неправильний розділювач дробів, програма перехоплює `InputMismatchException`, очищує буфер сканера та пропонує спробувати ще раз.
* **Локалізація**: Використовується кодування `UTF-8` для коректного відображення українського тексту в консолі.
